# Inicio rápido

1. Instala el complemento de Navisworks y el paquete de tu cliente: [guía](INSTALL.md).
2. Abre la federación en Navisworks Manage.
3. Pide: «Comprueba NavisCoord y analiza el modelo abierto sin modificarlo».
4. Revisa disciplinas, cobertura de tests y plan de trabajo.
5. Revisa la vista previa antes de aplicar cambios. Repite el análisis cuando cambie el modelo.

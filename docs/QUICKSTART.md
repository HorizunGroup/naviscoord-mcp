# Quick start

1. Install the Navisworks add-in and your desktop client package: [installation guide](INSTALL.md).
2. Open your federation in Navisworks Manage.
3. Ask: “Verify NavisCoord and analyze the current model without changing it.”
4. Review discipline mappings, test coverage and the proposed work plan.
5. Preview changes before applying them. Reanalyze after model or test changes.
